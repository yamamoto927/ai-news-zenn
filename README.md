# ai-news-zenn

生成AI関連ニュースを毎日自動で収集・要約し、Zenn に **下書き** として投稿するリポジトリです。
人間は Zenn のダッシュボードで下書きを読むだけで、日々のニュースを把握できます。

## 全体の流れ

```
毎朝 7:00 JST
 ┌──────────── Anthropic クラウド（Claude Code ルーティン）────────────┐
 │ メインエージェント（Claude Opus 5.5）                                  │
 │  1. リポジトリを取得し CLAUDE.md（手順書）を読む                        │
 │  2. 今日分が既にあれば終了（二重投稿防止）                              │
 │  3. Web検索でニュースを探し、記事ページを実際に開いて内容と日付を確認     │
 │  4. 重要度で選別し、下書きを最大4本作成                                 │
 │  5. 校閲エージェント（fact-checker）が出典と記事を突き合わせて指摘        │
 │  6. 指摘を反映（必要なら再校閲、最大2回）                               │
 │  7. main に push                                                     │
 └──────────────────────────────────────────────────────────────────────┘
        ↓
 GitHub（このリポジトリの articles/）
        ↓ Zenn の GitHub 連携で自動取り込み
 Zenn（published: false の下書き）
        ↓
 人間がダッシュボードで読む
```

## 構成要素

| 要素 | 場所 | 役割 |
|---|---|---|
| 手順書 | [CLAUDE.md](CLAUDE.md) | 収集・選別・執筆・校閲・失敗時対応・テンプレートを定義 |
| 校閲エージェント | [.claude/agents/fact-checker.md](.claude/agents/fact-checker.md) | 記事を出典と突き合わせ、指摘だけを返す（記事は編集しない） |
| ルーティン | Claude Code のクラウドルーティン | 毎日 22:00 UTC（7:00 JST）に起動。モデルは Claude Opus 5.5。使用ツールは Web検索・Webページ取得・ファイル操作・git・サブエージェント呼び出しのみで、Gmail 等の外部サービス接続は付けていない |
| クラウド環境 | Claude Code のクラウド環境設定 | ネットワークアクセスは許可したドメインのみに制限（カスタム許可リスト） |
| Zenn | GitHub 連携（main ブランチ） | push された記事を下書きとして表示 |

## 1日の投稿構成

| 種類 | ファイル名 | 本数 |
|---|---|---|
| 重要トピック記事 | `articles/ainews-YYYYMMDD-t1〜t3.md` | 最大3本 |
| その他まとめ | `articles/ainews-YYYYMMDD-misc.md` | 最大1本 |
| 失敗報告 | `articles/ainews-YYYYMMDD-error.md` | 失敗時のみ |
| 特集記事（手動依頼） | `articles/feature-YYYYMMDD-<スラッグ>.md` | 依頼時に1本 |

## 設計上の方針

- **下書き固定**：Zenn の利用規約は「機械により自動生成された文章の投稿」をスパム行為として禁止しているため、すべて `published: false` で作成し、公開は人間が内容を確認・加筆してから手動で行う。
- **確認できた事実だけを書く**：記事ページを実際に開いて確認できたニュースのみ掲載し、出典URLを必ず付ける。
- **書く役とチェックする役を分ける**：執筆したエージェントとは別の校閲エージェントが出典と照合する。
- **失敗を下書きで知らせる**：処理を完了できなかった場合は「【要確認】」の失敗報告を下書きとして残す。
- **著作権への配慮**：要約は自分の言葉で書き、元記事の画像や文章を転載しない。
