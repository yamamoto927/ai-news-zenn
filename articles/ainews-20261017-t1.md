## 概要

AI スタートアップの **Reflection AI** は2026年10月16日、同社初のオープンウェイトモデル **「Beam」の重みを Hugging Face で公開**しました。総パラメータ数は **5,010億（1トークンあたりに使うのは230億）** の MoE（Mixture-of-Experts：複数の「専門家」ネットワークから一部だけを動かす構成）モデルで、コーディングやエージェント的な長時間の作業を主な用途としています。ライセンスは商用利用もしやすい **Apache 2.0** です。Beam 自体は10月5日に発表されていました。

- **発表元**：Reflection AI
- **発表日**：2026/10/16
- **ポイント**：5,010億パラメータ級のモデルを Apache 2.0 で公開し、40を超えるパートナー経由でも提供

## このニュースの影響

- **エンジニア・開発者**：BF16・FP8・NVFP4 の3種類の重みが公開され、Transformers・vLLM・SGLang で初日から使えます。NVFP4 版は約280GB で、B200 を4基程度から動かせるとされており、自前の GPU 環境で大型モデルを試す選択肢になります。
- **企業・ビジネス**：Apache 2.0 のため、独自ライセンスの制約を気にせず自社製品への組み込みや追加学習を検討しやすくなります。AWS・Google Cloud・Microsoft Azure などのクラウドに加え、Dell と HPE がオンプレミスや外部と切り離した環境向けに提供するとしており、データを社外に出せない組織でも導入しやすくなる可能性があります。

## 詳しく

- **構成**：52層、MoE 層ごとに256個の専門家を持ち、1トークンあたり8個を使います。文脈長は100万トークンで、入出力はテキストのみです。
- **ベンチマーク（Reflection の自社報告、BF16 版）**：SWE-bench Verified 81.6%、Terminal Bench v2.1 80.1%、AIME 2026 97.7%、GPQA Diamond 90.6% など。
- **必要な機材の目安**：BF16 版は重みだけで約1TB（例：H200 を16基）、FP8 版は H200 8基などの Blackwell 以前の GPU 向け、NVFP4 版は B200 4基が最小構成の目安とされています。
- **同時に公開されたもの**：安全性の技術レポート、ターミナルから Beam を使うためのオープンソースのエージェント実行環境「Mirror CLI」、強化学習や追加学習のレシピなど。
- **提供経路**：Hugging Face のほか、Reflection 自身の API（パブリックベータ、「無料で始められる」としています）、Together AI・Fireworks AI・Baseten などの API 事業者、Ollama・OpenRouter などで利用できます。Reflection はパートナーと連携先が40を超えるとしています。

## なぜ重要か

2026/10/16 に取り上げた Meta の「Muse Spark Open」に続き、大型オープンウェイトモデルの公開が相次いでいます。Muse Spark Open が商用利用に条件のある独自ライセンスだったのに対し、Beam は Apache 2.0 で公開された点が特徴で、企業が自由に改変・再配布できる大型モデルの選択肢が広がります。
