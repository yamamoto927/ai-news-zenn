## 概要

AI コーディングエディター **Cursor** の拡張機能マーケットプレイスで、Anthropic の「Claude Code」拡張機能を装った**不正なバージョン 2.1.313** が配布されていたと、セキュリティメディアの The Hacker News が10月30日に報じました。正規の発行元名と拡張機能 ID を使っており、インストールすると攻撃者の SSH 鍵を仕込むなどの動作をしたとされます。Cursor は影響を受けたユーザーを**最大5,000人**としています。

- **発表元**：The Hacker News（Cursor・Anthropic の対応を報道）
- **発表日**：2026/10/30
- **ポイント**：AI コーディングツールの拡張機能がサプライチェーン攻撃の標的に

## このニュースの影響

- **エンジニア・開発者**：Cursor で Claude Code 拡張機能を自動更新していた人は、影響を受けた可能性があります。報道では、該当端末の隔離、不正な SSH 鍵や常駐設定の削除、認証情報やセッションの更新が推奨されています。
- **企業・ビジネス**：開発者の端末に AI 拡張機能を入れている組織では、拡張機能の自動更新や配布元の管理を見直す必要が考えられます。開発端末の環境変数には API キーなどが含まれることが多く、情報流出のリスク評価が求められます。

## 詳しく

- **配布の経路と期間**：不正版は Cursor Marketplace で配布され、太平洋時間の**10月29日午前2時27分ごろから午後1時35分ごろ**まで入手可能だったとされます。自動更新を有効にしていたユーザーが受け取った可能性があります。Open VSX や Microsoft の VS Code Marketplace に届いた形跡はないとされています。
- **Cursor の説明**：Cursor はこのバージョンが Anthropic によって開発されたものではないと説明し、問題のパッケージを削除するためにマーケットプレイスを一時停止し、不正版は削除されました。攻撃者がどうやって更新を登録したかは明らかになっていません。影響を受けたユーザーには Cursor から直接連絡するとしています。
- **Anthropic の対応**：Anthropic は正規の**バージョン 2.1.314** を Open VSX と VS Code Marketplace に公開しました。
- **不正な動作**：エディター起動時などに動き出し、「svc-telemetry」という名前の攻撃者の SSH 鍵を `~/.ssh/authorized_keys` に追加し、外部サーバーへのリバーストンネルを開いたうえで、タスクスケジューラ・crontab・LaunchAgent で常駐化を図ったとされます。さらにホスト名やユーザー名のほか、KEY や TOKEN を含む環境変数の名前などを暗号化されていない HTTP で送信していたと報じられています。現時点で追加のマルウェアの送り込みは確認されていないとのことです。

## なぜ重要か

AI コーディングツールは開発者の端末で広い権限を持って動くため、その拡張機能が乗っ取られると影響が大きくなります。今回は正規の発行元名と ID が使われており、利用者が見た目で見分けるのは困難でした。AI 開発ツールの普及に伴い、配布経路の安全性があらためて問われる事案です。
