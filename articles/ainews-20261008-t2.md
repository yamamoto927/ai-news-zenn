## 概要

**Microsoft** が10月7日（米国時間）、サンフランシスコで開いたイベントで、NVIDIA の **RTX Spark** チップを搭載した「**Surface Laptop Ultra**」などの AI PC と、刷新した Windows 11 の AI 機能を発表しました。ローカル（手元の PC）とクラウドの AI を使い分ける「**ハイブリッドインテリジェンス**」を掲げ、AI エージェントを隔離して動かす実行環境「**Microsoft Execution Containers（MXC）**」の一般提供も始めました。

- **発表元**：Microsoft
- **発表日**：2026/10/07（米国時間）
- **ポイント**：AI モデルを手元で動かせる PC と、エージェントを安全に動かす OS の仕組みをセットで提示

## このニュースの影響

- **エンジニア・開発者**：MXC では、エージェントがアクセスできるファイルやネットワークを組織が定義し、実行時に強制できます。ITmedia AI+ によると、OpenAI Codex や GitHub Copilot などがすでに対応し、Anthropic の Claude Code なども対応予定です。また、クラウドとローカルのモデルにタスクを振り分ける GitHub の「HydraFusion」を、ローカルモデルにも広げる実験的プレビューが10月中に予定されています。
- **一般の利用者**：Copilot+ PC 向けに、PC 内のファイルや最近の作業を理解したり、ファイル整理やトラブル対応を行ったりする Copilot のローカル機能が、今後数か月かけて提供される予定です。
- **企業・ビジネス**：ITmedia AI+ によると、Microsoft は AI の利用需要がクラウド予算を上回りつつあると説明しています。処理の一部を手元の PC に移すことで、トークン消費（クラウド AI の利用料）を抑える選択肢になる可能性があります。

## 詳しく

- **Surface Laptop Ultra**：TechCrunch によると、米国での価格は2つの基本構成が **2,600ドル** と **3,700ドル** からで、最上位は5,900ドルです。ITmedia AI+ によると、最大128GB のユニファイドメモリーを積み、1,200億パラメータを超える AI モデルをローカルで動かせるとされます。日本での価格は24GB モデルが51万3,480円からです。
- **Surface RTX Spark Dev Box**：開発者向けのワークステーションで、TechCrunch によると6,000ドルから。VS Code や GitHub Copilot CLI、WSL などがプリインストールされます。
- **他社製 PC**：ASUS、Dell、HP、Lenovo、MSI からも RTX Spark 搭載 PC が登場し、ITmedia AI+ によると10月16日から順次出荷されます。
- **MXC**：プロセス／セッション単位の分離、WSLc、仮想マシン、Windows 365 for Agents といった分離方式を選べ、Microsoft Agent 365 や Intune と連携して組織全体で管理できます。TechCrunch によると、すべての Windows 11 ユーザーが利用できるようになるとしています。
- **ローカルモデル**：コーディング向けの「MAI Code 1.1 Flash」（総パラメータ1,370億、アクティブ68億）を3ビット量子化（数値の精度を落としてモデルを小さくする手法）でローカル実行できるとしています。
- **Copilot の新構成**：「Home」「Code」「Autopilot」の3つで構成され、Autopilot はユーザーが別の作業をしている間も動き続ける常駐型の個人エージェントです。
- Microsoft の Satya Nadella CEO は、モデルがあるだけでは何も起きないという趣旨を述べ、自社アプリだけでなくあらゆるエージェントのための基盤を作ると話しました（TechCrunch）。
