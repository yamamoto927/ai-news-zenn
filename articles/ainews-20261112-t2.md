## 概要

Google は11月11日、文章を生成する代わりに、あらかじめ決めた選択肢を採点して判断を返す新しい API **「Gemini Decisions API」** を発表しました。使うモデルは **「Gemini Decision 1」** で、テキスト・画像・音声・動画・PDF を1回の処理で読み取り、はい／いいえや多肢選択などの問いに確率付きで答えます。料金は **入力100万トークンあたり0.10ドル、出力は0ドル** です。

- **発表元**：Google（Google DeepMind）
- **発表日**：2026/11/11
- **ポイント**：ツール選択やモデルの振り分けなど「決めるだけ」の処理を高速・低コストにする専用 API

## このニュースの影響

- **エンジニア・開発者**：Gemini API と Google AI Studio から使え、Python・JavaScript・REST のガイドが用意されています。AI エージェントのツール選択、ポリシー判定、モデルの振り分け（ルーティング）などを、通常の LLM に文章を生成させるより安く速く組める可能性があります。OpenRouter、LangChain、Vercel、LiteLLM などとの連携も順次提供されます。

## 詳しく

- **入力**：最大25万6,000（256K）トークンの共有入力に対して、1回のリクエストで最大1,000個の独立した問いを投げられます。
- **問いの種類**：はい／いいえの確率を返す形式、2〜255個の選択肢から選んで全候補の確率を返す形式、段階評価（ルーブリック）で採点する形式の3種類です。
- **速度**：エンドツーエンドで150〜250ミリ秒、モデルの計算時間の中央値は50〜100ミリ秒としています。問いが1個でも100個でも遅延はほぼ変わらないとしています。
- **性能（Google 発表）**：エージェントのルーティングや推論、ランキング、マルチモーダル理解の社内ベンチマーク群で首位となり、確率のずれ（較正誤差）が最も小さかったとしています。同じベンチマーク群では Gemini 3.5 Flash-Lite より5倍近く安いとしています。
- **社内での利用例**：Gemini Notebook での問い合わせの振り分け（日常的な質問で最大40%の遅延削減）、Google 検索での MCP ツール向けの安全確認などに使われています。
- **提供状況**：Google AI Studio では試作向けの無料枠があります。Google Cloud の Gemini での対応は「近日」とされています。
