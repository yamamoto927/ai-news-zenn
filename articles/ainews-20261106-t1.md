## 概要

OpenAI は米国時間 11月5日、脆弱性の調査やエクスプロイト（脆弱性を実際に突く攻撃コード）の開発に特化したモデル **「GPT-6 Cyber」** を発表しました。攻撃にも転用できるため、まずはセキュリティプログラム「Daybreak」の上位区分 **Daybreak Red の承認済み顧客の一部** に限って提供します。OpenAI によると、Linux カーネルの検証では **948件の脆弱性について動作する攻撃コード** を作り、Firefox では未知の深刻な脆弱性を81件見つけたとしています。

## 詳しく

- **提供範囲**：最初は Daybreak Red の一部顧客に API と Codex を通じて提供し、今後数週間で Daybreak Red の全顧客に広げるとしています。Daybreak Red は模擬攻撃やレッドチーミング（攻撃者の立場での検証）向け、Daybreak Blue はコードレビューやマルウェア解析など防御向けの区分です。
- **安全性評価**：OpenAI は自社の安全性評価の枠組み「Preparedness Framework」のサイバーセキュリティ分野で、このモデルを **「Critical」** と評価していると報じられています。
- **Linux カーネルでの検証**：1,724件の脆弱性を再現し、948件で動作する攻撃コードを作成しました（前モデルは同条件で166件）。948件には、これまで知られていなかった588件が含まれると報じられています。304件の重大な発見は修正案とともに保守者へ報告したとされ、検証にかかった計算コストは約121万ドルと報じられています。
- **Firefox での検証**：未知の深刻な脆弱性を81件見つけ、Mozilla が報告を受け入れて修正を出しているとされています。
- **ベンチマーク**：OpenAI の発表として、攻撃コード作成の評価「ExploitGym」で 48.5%（GPT-5.6 Cyber は 32.1%）と報じられています。いずれも OpenAI による数値です。
