## 概要

**Google** は 2026年9月30日、新しいフロンティアモデル（最先端の大規模モデル）**「Gemini 4 Argon」** を発表しました。実務的なソフトウェア開発、法務・金融などの企業向け知識労働、サイバーセキュリティ防御を主な用途とし、出力トークン上限を従来の6万4,000から **100万トークン** に広げたのが特徴です。まずは信頼できるサイバー防御の担当者向けプログラム「Fairwind Program」から段階的に提供し、その後に有料 API 利用者や Google AI Ultra の加入者へ広げるとしています。

- **発表元**：Google（Google DeepMind）
- **発表日**：2026/09/30
- **ポイント**：Gemini 4 世代の最上位モデル。長時間の複雑な作業向けで、まずは限定提供

## このニュースの影響

- **エンジニア・開発者**：出力上限が100万トークンになることで、大規模なコード移行や長文ドキュメントの生成など、1回の応答で扱える作業の規模が大きくなる可能性があります。ただし現時点では限定提供のため、一般の開発者がすぐ API で使えるわけではありません。
- **企業・ビジネス**：導入価格は入力100万トークンあたり2ドル、出力10ドルと示されており、正式価格（入力4ドル・出力20ドル）に移行する前に試せるかどうかが、評価・選定のタイミングに関わってきます。
- **一般の利用者**：一般向けには Google AI Ultra 加入者から順次提供される予定で、それ以外の利用者が使えるようになる時期は示されていません。

## 詳しく

- Google DeepMind の Koray Kavukcuoglu 氏（SVP）が公式ブログで発表しました。長時間・多段階の作業でも深い推論を持続できるよう設計したと説明しています。
- Google が示した主なベンチマーク結果は次のとおりです。
  - 実務的なソフトウェア開発を測る **DeepSWE v1.1 で 77.9%**
  - セキュリティ脆弱性の修正を測る CWE-bench v1 で 68%
  - 長尺動画の理解を測る LVBench で 91.7%
  - AutomationBench で 51.3%
- 9to5Google によると、DeepSWE v1.1 では Claude Opus 5.5（74.2%）や GPT-6 Astra（74.1%）を上回りました。一方 VentureBeat は、公表された18のベンチマークのうち13で首位または同率首位としつつ、FrontierSWE v2 では GPT-6 Astra が10.5ポイント上回っていると指摘しています。
- 料金は導入期間中が入力100万トークンあたり2ドル・出力10ドルで、キャッシュされた入力は入力料金の95%引きです。導入期間後は入力4ドル・出力20ドルになります。
- 提供はまず Fairwind Program を通じたサイバー防御の担当者向けで、米国政府の自主的な公開前モデル評価の枠組みにも参加しながら、段階的に対象を広げるとしています。
