## 詳しく

**ETH とは**
- 「3-SAT などの難しい問題は、変数の数に対して指数時間より本質的に速くは解けない」という仮説で、1999年に UC San Diego の Russell Impagliazzo 氏と Ramamohan Paturi 氏が提唱しました。P≠NP 予想を補強する根拠の一つとされてきました。

**OpenAI の公開（TechCrunch による）**
- 3つの問題への解答を、分野ごとに異なる方法で公開しています。数学者向けには GitHub で公開しました。計算機科学者は自らワーキンググループを作り、証明の公開と、議論する会議への OpenAI の資金支援を求めました。物理学者向けの結果は、同分野のワーキンググループが公開方法を決めるとされています。
- Anthropic の数学者 Levent Alpöge 氏は、OpenAI の解答が既存の研究に依拠していると指摘したと報じられており、その数時間後に Anthropic が独自の成果を公開したとされています。

**Anthropic の公開（GitHub による）**
- 論文「A 2^{o(n)} Time Algorithm for 3-SAT」と Lean 4 の形式証明を公開。3-SAT の解の個数を数える #3-SAT についても、指数より速い時間で解けると主張しています。
- 結果は社内研究用の Claude モデルが発見し、Lean による形式化も AI モデルが書いたとしています。
