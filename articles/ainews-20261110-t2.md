## 概要

Meta は11月9日（米国時間）、同社で最も小さく効率的なモデル **「Muse Ember」** を公開しました。ツール呼び出し、コーディングの小さな作業、振り分け（ルーティング）、情報抽出など、AI エージェントが繰り返し行う処理向けに作られています。料金は **入力100万トークンあたり0.10ドル、出力0.50ドル** で、コンテキスト長は **100万トークン** です。

- **発表元**：Meta（Meta Superintelligence Labs）
- **発表日**：2026/11/09（米国時間）
- **ポイント**：Anthropic の Haiku 5.5 や OpenAI の GPT-6 Luna と同クラスの性能を、より低いコストで実現したと Meta は主張

## このニュースの影響

- **エンジニア・開発者**：`muse-ember-1.0` として Muse Code と Meta Model API、Google Cloud、Oracle Cloud で使え、Responses API にも対応します。大量の定型処理を安価なモデルに任せ、計画は上位モデルに任せる構成を組みやすくなる可能性があります。
- **企業・ビジネス**：軽量モデルの価格競争がさらに進み、エージェントを大規模に動かす際のコスト見積もりに影響すると考えられます。

## 詳しく

- **仕様**：コンテキストは100万トークン、出力は最大51万2,000トークン。テキスト・画像・音声で学習されており、スクリーンショットやグラフ、スキャン文書も別のモデルなしで扱えるとされています。
- **料金**：入力0.10ドル、キャッシュ済み入力0.004ドル、出力0.50ドル（100万トークンあたり）。20万トークンを超えるプロンプトは、入力0.30ドル／出力1.50ドルになります。
- **ベンチマーク（Meta 発表）**：AutomationBench-AA で **37.8%**（Haiku 5.5 は13.9%、GPT-6 Luna は20.2%）。一方、FrontierCode 2.0-AA では27.2%で、Haiku 5.5 の34.9%を下回っています。Meta は、Haiku 5.5 の最高スコアに約3分の1のコストで並ぶとしています。
- **使い方の想定**：TechCrunch によると、Meta はフロンティアモデル「Muse Wonder」と組み合わせ、Wonder が計画し Ember が大量の処理をこなす構成を想定しています。
- **注意点**：Meta のブログは、結果の一部は社内評価や特定の評価環境・部分点方式によるものだと注記しています。
