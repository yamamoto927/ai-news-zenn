### OpenAI、API の処理と推論を日本国内で完結できる機能を提供 — まず「GPT-6 Luna」から

OpenAI は11月11日、**API リクエストの処理とモデルの推論を日本国内で行える機能** の一般提供を始めました。対象は **GPT-6 Luna** のみで、Responses API と Chat Completions API で使えます。利用には、データを保存しない設定（ZDR：Zero Data Retention）の事前承認、保存先と処理場所に日本を選んだ新しい API プロジェクトの作成、日本向けエンドポイントの利用などが条件で、従量課金の「Standard」ティアのみが対象です。

**このニュースの影響**：金融・通信・医療・行政など、データを国内で扱うことが求められがちな分野の企業や開発者は、OpenAI の API を採用しやすくなる可能性があります。ただし ChatGPT や Codex、音声・画像生成、OpenAI がホストするツールは対象外で、すべての処理が国内で完結することを保証するものではない点に注意が必要です。

**なぜ重要か**：2025年5月に発表した国内でのデータ保存に続き、処理そのものも国内で行えるようにした拡張です。

### NTT、ロボットが動く前に結果を予測する「NTTワールドモデル」— 棚積みの成功率が92.3%に
