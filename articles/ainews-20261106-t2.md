## 概要

OpenAI は米国時間 11月4日、ChatGPT の画像生成機能を **「ChatGPT Images 2.6」** に更新しました。ITmedia によると、前版の Images 2.5 から **生成速度が50％向上** し、ループする **GIF アニメーションの生成** にも対応します。開発者向けには、速度重視の **「GPT-Image-2.6 Flare」** と品質重視の **「GPT-Image-2.6 Sunburst」** の2つの API モデルを用意しました。

- **発表元**：OpenAI
- **発表日**：2026/11/04（米国時間）
- **ポイント**：無料プランを含む全プランで提供、API は料金据え置きで2モデル構成に

## このニュースの影響

- **エンジニア・開発者**：用途に応じて Flare（速度）と Sunburst（品質）を選べるようになり、料金は Images 2.5 から据え置きのため、コストを変えずに移行を検討しやすくなります。SVG 書き出しや画像への注釈による修正指示も使えます。
- **一般の利用者**：無料プランでも新しい画像生成が使え、手描きスケッチを動くアニメにするなどの GIF 作成ができるようになります（GIF 生成は順次展開）。
- **企業・ビジネス**：ポスターや商品画像のレイアウト品質が改善されたとされ、販促素材づくりへの活用の幅が広がる可能性があります。

## 詳しく

- **提供範囲**：ChatGPT と Codex の全プラン（無料プランを含む）で、Web・デスクトップ・モバイルから利用できます。
- **主な新機能**：
  - 編集精度の改善（背景を変えても衣装などの細部を保ちやすい）
  - ループアニメの GIF 生成、再生速度の調整
  - 写真に名前を付けて保存し、別のチャットで「@名前」のように呼び出して再利用できる機能
- **API モデル**：
  - **GPT-Image-2.6 Flare**：低画質設定で最短6秒で生成
  - **GPT-Image-2.6 Sunburst**：中〜高画質設定向けで、編集を重ねても一貫性を保ちやすい
  - 生成前の検討の度合いを調整する「complexity」パラメータを追加
- **API 料金**（両モデル共通・据え置き、100万トークンあたり）：画像入力8ドル、画像出力30ドル、テキスト入力5ドル。
- **安全対策**：GIF 特有の有害な動きを判定する仕組みを追加し、出所確認のため C2PA メタデータに加えて Google DeepMind の電子透かし技術「SynthID」を導入しました。
- **評価**：AIbase によると、比較サイト Arena の Text-to-Image 部門で Sunburst（Medium）が2位、Flare（Medium）が4位に入ったとされています。
- **利用規模**：ChatGPT・Codex・API で、生成枚数は週に約40億枚に上るとしています。
