## 概要

中国の AI 企業 **DeepSeek** は2026年10月17日、主力の軽量モデルを更新した **「DeepSeek-V4.1-Flash-1017」** を公開しました。同社サイト・アプリ・API で使えるほか、重みは Hugging Face と ModelScope で **MIT ライセンス** のもと公開されています。同時に、自社の検索エンジンを使う **「Search」「Fetch」API の提供を開始** し、料金は **各1,000回あたり0.75ドル** としています。

## このニュースの影響

- **エンジニア・開発者**：API の `deepseek-flash` は呼び出し方を変えずに新モデルへ切り替わっています。旧名の `deepseek-v4-flash` や `deepseek-v4-flash-vision-exp` も引き続き受け付けられるため、移行作業は基本的に不要です。ただし応答の傾向（出力の長さなど）が変わる可能性があるため、既存の処理の確認は必要と考えられます。

## 詳しく

- **改善点**：DeepSeek は、ベンチマーク性能の向上と作業時間・出力長の短縮を同時に実現したとしています。強化学習に自己フィードバックを組み合わせ、プロジェクトを最初から最後まで作り上げる力を高めたと説明しています。
- **ベンチマーク（Hugging Face のモデルカード、DeepSeek の自社報告）**：Terminal-Bench 4.0 で 42.3（前版 31.2）、DeepSWE v1.1 で 77.0（同 74.2）、HLE（ツールなし）で 42.6（同 36.8）など。同じ表では Opus 5 が Terminal-Bench 4.0 で 51.8、HLE で 56.3 と、項目によっては他社モデルを下回っています。
- **仕様**：文脈長は100万トークン。テキストに加えて画像も入力でき、ツール呼び出しや思考モードに対応します。vLLM・SGLang などでのローカル実行手順も示されています。
- **対応ツール**：自社の DeepSeek Harness や Tencent の CodeBuddy・WorkBuddy 向けに最適化したとしています。
- **Search / Fetch API**：自社開発の検索エンジンを使い、Web 検索とページ取得をそれぞれ API で提供します。
