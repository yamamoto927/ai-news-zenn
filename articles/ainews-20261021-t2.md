## 概要

**Google** は2026年10月20日、PyTorch Conference 2026 にあわせて、PyTorch のプログラムを自社の AI 向けチップ TPU でネイティブに動かすためのソフトウェア **「TorchTPU」をオープンソース化** しました。Meta の PyTorch チームと共同開発したもので、既存の PyTorch のコードを **最小限の変更で TPU 上で実行** できるとしています。前日の Amazon による「TorchNeuron」発表に続く動きで、TechCrunch は NVIDIA の牙城である AI 開発者を取り込む動きと位置付けています。

- **発表元**：Google（Google Cloud）
- **発表日**：2026/10/20
- **ポイント**：PyTorch をそのまま TPU で動かせるようにし、GPU 以外の選択肢を広げる

## このニュースの影響

- **エンジニア・開発者**：PyTorch で書いたモデルの学習・推論を、コードを大きく書き換えずに TPU で試せるようになります。Hugging Face Transformers v5 では `device_map="tpu"` を指定するだけで TPU に載せられるとされ、vLLM や SGLang などの推論エンジンも TPU に対応しています。
- **企業・ビジネス**：GPU の調達やコストが課題の企業にとって、Google Cloud の TPU が現実的な選択肢になる可能性があります。NVIDIA の GPU に依存しない構成を検討しやすくなると考えられます。

## 詳しく

- **ライセンスと入手方法**：GitHub の「google-pytorch/torch_tpu」で公開され、ライセンスは Apache 2.0 です。PyPI からもインストールできます。
- **主な機能**：デバッグ向けの eager モード（1行ずつ即時実行する方式）と、本番向けの `torch.compile` に対応し、診断機能や分散処理の仕組みも備えています。
- **連携するエコシステム**：Hugging Face（Transformers、Diffusers）、vLLM（Inferact）、SGLang（RadixArk）、分散推論の llm-d 1.0、TorchTitan、VeRL、Ray などと連携しています。端末向け実行環境 LiteRT（旧 TensorFlow Lite）も PyTorch のエコシステムに加わりました。
- **性能の例**（Google 発表）：TorchTitan で Qwen 3 8B を学習した際、モデル FLOPs 利用率（MFU、チップの理論性能をどれだけ使えたか）が最大52%に達し、最大8,192基の Ironwood TPU（TPU v7x）まで、ほぼ線形にスケールしたとしています。
- **移行支援ツール**：アプリの TPU への移行や診断、推論の調整を支援する「TPU agent suite」もプレビュー提供されています。
- **競合の動き**：TechCrunch によると、Amazon も前日の10月19日に、PyTorch アプリを自社チップ Trainium に移せる「TorchNeuron」を発表しています。

## なぜ重要か

AI 開発で広く使われる PyTorch は、NVIDIA の GPU を前提に発展してきたため、GPU 以外のチップへの移行には手間がかかっていました。Amazon と Google が相次いで PyTorch からの移行の手間を減らすツールを出したことで、クラウド各社による AI チップの選択肢の競争が、ソフトウェアの使いやすさの面でも本格化しています。
