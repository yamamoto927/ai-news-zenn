## 概要

Anthropic は **11月23日（米国時間）**、プルリクエスト（PR：コード変更の取り込み依頼）のレビューから修正、マージ可否の判断までを AI エージェントが担う **「Claude Ship」** を発表しました。チームがリポジトリに置いた方針ファイルに従い、定型的な変更は **AI が自動で承認** できるのが特徴です。Claude Ship はベータ版として **Claude Team / Enterprise プラン** の GitHub リポジトリ向けに提供され、構成要素のうち Code Review のみ一般提供です。

- **発表元**：Anthropic
- **発表日**：2026/11/23（米国時間）
- **ポイント**：コードを「書く」だけでなく「出荷してよいか判断する」工程まで AI に任せられるようにする

## このニュースの影響

- **エンジニア・開発者**：CI の失敗やマージの衝突（コンフリクト）への対応、レビュー指摘の反映を AI に任せられるため、PR を出したあとの手作業が減る可能性があります。Claude Code では `/ship` コマンドで、push から PR 作成、レビュー、指摘への対応までを一続きで実行できます。
- **企業・ビジネス**：承認の基準を自然言語の方針ファイルで決められる一方、Anthropic は、まず「観察のみ」モードで1つのリポジトリから始め、月ごとの利用上限を設定することを勧めています。トークン課金のため、運用ルールの整備が必要になります。

## 詳しく

Claude Ship は次の3つの機能で構成されます。

- **Code Review（一般提供）**：PR をコードベース全体と照らし合わせて複数の観点から確認し、指摘を分類して PR に投稿します。リポジトリごとに Quick / Standard / Deep の3段階から深さを選べます。
- **PR Steward（ベータ）**：失敗した CI、マージの衝突、レビュー指摘に対応します。承認やマージはしません。push のたびに、何を変えたかと元に戻す方法をコメントします。`@claude` で指示を出し、`@claude stop` で止められます。
- **Claude Approvals（ベータ）**：チームがリポジトリに置いた承認方針ファイルに従い、定型的な変更は自動で承認し、それ以外は人の承認を求めます。Code Review の指摘や、自然言語で書いた分類器（クラシファイア）を判断材料にできます。

このほかの主な点は次のとおりです。

- **提供範囲**：Claude Team / Enterprise プランの GitHub リポジトリが対象です。ゼロデータ保持（ZDR）や HIPAA 向け構成、顧客管理の暗号鍵を使う組織は対象外です。
- **料金**：トークン量に応じた課金です。Claude Approvals には基本料金がありませんが、分類器の利用はトークン課金されます。管理者は Code Review と PR Steward に利用上限を設定できます。
- **キャンペーン**：対象の Enterprise 組織は **1万ドル以上** の Claude Ship クレジットを受け取れます（申し込み期限は2027年1月15日、受け取り後30日以内に利用）。
- **社内での実績**：Claude Code チームでは、6月から9月にかけてマージされた PR が **2倍超** に増え、取り消された変更の割合は40%超減ったとしています。
- **既存の仕組みとの関係**：GitHub のブランチ保護や必須チェックと組み合わせて使えます。

## なぜ重要か

AI エージェントが大量のコードを書くようになり、人によるレビューと承認が開発の詰まりどころになっています。Claude Ship は、その「書いたあと」の工程まで AI に任せる試みです。とくに、方針に基づいて AI が承認まで行う点は、ソフトウェア開発で人と AI がどう役割を分けるかに関わる動きといえます。
