## 概要

**Google** は2026年10月28日（米国時間）、企業や開発者が自社のアプリやサービスを **Gemini アプリと Google 検索の AI 体験** に組み込めるようにする **「Connected Apps Platform」** のプレビューを発表しました。開発者はクラウド上の **MCP サーバー**（MCP：AI とアプリ・データをつなぐための共通の接続方式）または Android の MCP を使って接続し、新しい管理画面「Google Connected Console」で登録・テスト・申請を行います。現在は米国の開発者向けのプレビューで、順番待ちリストへの登録が必要です。

- **発表元**：Google
- **発表日**：2026/10/28（米国時間）
- **ポイント**：外部アプリを Gemini と検索の AI から呼び出せる「Connected Apps」を、一般の開発者にも開放

## このニュースの影響

- **エンジニア・開発者**：MCP サーバーまたは Android の AppFunctions API を用意すれば、自社サービスを Gemini や検索の AI から呼び出せるようになります。公開後はトラフィック、レイテンシ、エラー率を確認できます。
- **一般の利用者**：Gemini や検索の中から、外部サービスを使った操作（例：Canva でチラシを作る、YouTube Music でプレイリストを作る）ができる場面が増える可能性があります。
- **企業・ビジネス**：TechCrunch は、AI エージェントの時代には、検索エンジン最適化（SEO）がウェブサイトの見つけやすさを左右したように、この仕組みがアプリの見つけられ方に影響しうると指摘しています。AI 経由で利用者に届く新たな経路として検討対象になると考えられます。

## 詳しく

- **接続方式**：クラウドでホストする MCP サーバー、または Android MCP（AppFunctions API を使用）で連携します。
- **管理画面**：「Google Connected Console」でアプリの登録、テスト、審査への申請をまとめて行えます。
- **掲載先の選択**：審査前に、検索、Gemini アプリ、またはその両方のどこに出すかを選べます。
- **公開後の管理**：トラフィックやエラー率などの確認に加え、認証済みロゴやアカウント認証などブランド表示を管理できます。
- **現在の提供状況**：検索と Gemini で50以上の Connected Apps が提供されており、Adobe、Experian、Localiza、Peloton などが Gemini で利用できます。これらの検索対応は今後数週間のうちに予定されています。瞑想アプリ Calm も両方での提供を始めるとしています。
- **今後**：対象となる開発者、市場、Google 製品を数か月かけて段階的に広げる予定です。一般提供の時期は示されていません。

## なぜ重要か

AI アシスタントから外部サービスを直接操作できるようにする取り組みは、OpenAI の ChatGPT や Meta の Muse でも進んでいます。Google が利用者の多い検索と Gemini の両方を対象に、MCP を接続方式として開放したことで、アプリ開発者にとって AI からの集客経路を巡る競争が本格化しつつあることを示しています。
