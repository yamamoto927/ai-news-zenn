## 概要

Anthropic は、Claude との会話で作ったアーティファクト（グラフや Web ページなどの生成物）を、**デスクトップアプリとしてインストールできる「Install as app」** を発表しました。Claude for Mac / Windows で、**全プラン向けにベータ版** として提供されます。インストールしたアプリは独自のアイコンとウィンドウを持ち、通知やメニューバー／システムトレイへの項目追加もできます。権限は3段階で、最上位の「フルアクセス」ではファイルの読み書きやプログラムの実行が確認なしで可能になります。

- **発表元**：Anthropic
- **発表日**：2026/11/24（米国時間）
- **ポイント**：会話で作ったツールを、パッケージ化や署名なしでそのまま PC アプリとして使えるようになった

## このニュースの影響

- **一般の利用者**：会議準備ページや出荷する注文の管理ツールなど、Claude で作ったツールを独立したアプリとして起動できます。アプリから Claude へのリクエストはプランの利用枠を消費する点に注意が必要です。
- **エンジニア・開発者**：パッケージ化・署名・API キー・別途ログインが不要で、他の人と共有することもできます。社内向けの小さなツールを配布する手段の一つになる可能性があります。
- **企業・ビジネス**：Team プランでは既定で有効（フルアクセスは無効）、Enterprise プランではオーナーが有効化する必要があります。Anthropic はインストール前にアプリを審査しないため、管理者による権限ルールの設定が重要になると考えられます。

## 詳しく

- アーティファクトの共有メニューから「Install as app」を選ぶとインストールできます。元のアーティファクトを編集すると、アプリも自動で更新されます。
- 権限は3段階です。
  - **既定**：Web ブラウザでできる範囲のみ
  - **アプリ権限**：常に最前面のウィンドウ、グローバルショートカット、通知など
  - **フルコンピューターアクセス**：プログラムの実行や、ファイルの読み取り・変更・削除を毎回の確認なしで実行
- 承認した権限はそのバージョンにだけ適用され、更新のたびに再承認が求められます。
- フルアクセスを付与できるのは、自分で作ったアプリか、Team / Enterprise プランで同じ組織のメンバーが作ったアプリに限られます。
- 利用にはインターネット接続と Claude へのサインインが必要です。HIPAA 対応組織とハイブリッド環境では使えません。Claude Docs / Slides / Sheets など一部のアーティファクトはインストールできません。
- ITmedia によると、Linux・Web ブラウザ版・モバイルは非対応で、Claude デスクトップアプリのバージョン 6.28899.0 以降が必要です。
