## 概要

中国の Tencent（テンセント）が、AI モデル「Hunyuan（混元）」シリーズの最新世代となる大規模言語モデル **「Hy4」の正式版** を11月4日に公開しました。プレビュー版から事前学習・事後学習の規模を広げ、Hy4 として初めて **画像の理解とコンピューター操作** に対応しています。パラメータ数は **7700億** と報じられており、Tencent の自社サービスに加えて OpenRouter など外部のプラットフォームからも利用できます。モデルの重み（学習済みパラメータ）とシステムカードは近く公開する予定としています。

- **発表元**：Tencent（Hunyuan チーム）
- **発表日**：2026/11/04
- **ポイント**：プレビュー版から正式版へ。画像理解とコンピューター操作を追加し、API 料金はプレビュー版から据え置き

## このニュースの影響

- **エンジニア・開発者**：OpenRouter などの API 経由で、画像入力やコマンドライン・GUI 操作を伴うエージェント用途に Hy4 を試せるようになりました。重みが公開されれば、自前の環境で動かす選択肢も加わる可能性があります。
- **企業・ビジネス**：標準の API 料金はプレビュー版と同じ（入力100万トークンあたり0.834ドル、出力100万トークンあたり2.501ドル）で、Tencent Cloud TokenHub では12月31日まで50%割引が適用されるため、低コストで評価しやすくなっています。
- **一般の利用者**：Tencent のアシスタントアプリ「Yuanbao（元宝）」や WeChat Work（企業向け WeChat）のアシスタントなどに搭載され、中国国内のサービスを中心に新機能が使えるようになります。

## 詳しく

- **追加された能力**：グラフや文書の読み取り、複数画像をまたいだ推論、コマンドラインツールや GUI（画面操作型のアプリ）の操作ができるようになったとされています。
- **学習の重点**：Blender や CAD ソフト、複数のアプリをまたぐ作業を対象に学習を行い、オフィス業務、財務分析、ゲーム開発を重点分野としています。社内の製品チームが実際の業務フローに沿って学習と評価に協力したとされます。
- **その他の改善**：指示への追従、長文の理解、長期的なタスク遂行能力も向上したとしています。
- **提供先**：Tencent Cloud TokenHub、WorkBuddy、CodeBuddy、Yuanbao、ima などで提供されています。WorkBuddy と CodeBuddy では11月4日〜15日に限定的な無料利用枠があります。外部では OpenRouter、Hermes、OpenCode などから API で利用できます。
- **今後の予定**：重みとシステムカードを近く公開する予定です（日付は未定）。より低コストな「Hy4 flash」も予定されていますが、時期は示されていません。
